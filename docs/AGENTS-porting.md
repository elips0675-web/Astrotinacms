# Правила портирования

> Публичная часть проекта — **порт** `D:\nlb-studio6-main` (React Router-приложение) в Astro.
> Главное требование: **внешний вид и поведение 1:1.** Это не редизайн и не «улучшение».

## Что разрешено менять

| Можно | Почему |
|-------|--------|
| Структуру маршрутов (`routes.tsx` → `src/pages/**.astro`) | Роутинг обязан жить в файловой структуре Astro |
| Импорты | Относительные пути вместо алиасов исходника |
| `size-9` → `h-9 w-9`, `size-4` → `h-4 w-4` | Классы v4 не существуют в Tailwind v3 |
| `rounded-xs` → `rounded-sm` | То же |
| `outline-hidden` → `outline-none` | То же |
| `react-router-dom` → шим `src/site/lib/router.tsx` | Роутинга нет в Astro |
| SSR-безопасность (`Notification.permission` под `typeof window`) | Иначе SSR-рендер падает |
| `export` на массивах данных | Данные читаются из `.astro`-фронтматтера |
| Graceful not-found на страницах деталей | В исходнике белый экран — это дефект, не фича |
| Фикс битых внутренних ссылок | Ссылки были биты в исходнике |

## Что запрещено

- **Менять разметку, классы, порядок элементов, тексты, цвета** публичных страниц «по вкусу».
- **Менять тексты** — это контент, а не код. Правка текста = правка данных.
- **Улучшать ссылки на картинки.** Даже мёртвые — они идентичны исходнику (см. pitfall 15). Замена меняет контент и ломает паритет; делать только по явному запросу.
- **Менять `slick.css` «на глаз».** Восстанавливать побайтово из исходника.
- **Удалять `getStaticPaths()`** «раз он не нужен в dev». В build он определяет весь набор страниц.
- **Упрощать `withRouter` до «мне тут ничего не нужно».** Он держит контекст внутри острова (pitfall 2).

Файлы, которые можно сверить побайтово, — сверять. Скрипты сравнения держать в `%TEMP%\opencode`.

```bash
node C:/Users/PC/AppData/Local/Temp/opencode/compare-src.mjs
node C:/Users/PC/AppData/Local/Temp/opencode/diff-src.mjs
```

## Грабли при переносе конкретных страниц

| Страница | Что ломается |
|----------|--------------|
| `/services` | `react-slick` interop (pitfall 1) + кастомный `slick.css` (9) |
| `/printing-services/[id]` | `getStaticPaths()` как **объединение** двух источников id (13) |
| `/news/[id]` | Роута нет в исходнике — создаётся заново; не расходиться с `newsItems` |
| `all-news-page.tsx` | Данные экспортируются наружу, чтобы `/news/[id]` брал тот же источник |
| `PushNotificationBanner.tsx` | `Notification` не существует при SSR |

## Что НЕ портировано и почему

| Не портировано | Причина |
|-----------------|---------|
| `page-templates/` | Мёртвый код в исходнике, ничего не импортирует |
| TinaCMS | Peer-конфликт: требует Astro 5–7, проект на 4.16.19 |
| PWA-логика сверх ассетов | В исходнике — заготовки; `manifest.json` и иконки перенесены |
| `/login` | Авторизации в проекте нет (см. `AGENTS-security.md`) |
